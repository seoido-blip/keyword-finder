# 🔑 네이버 키워드 파인더 (블랙키위 스타일)

시드 키워드를 넣으면 네이버 **연관 키워드**를 모으고, 키워드마다 아래 항목을 보여줍니다.

| 항목 | 출처 |
|---|---|
| 월간 검색량 (PC / 모바일 / 합계), 모바일 비중 | 네이버 검색광고 API |
| 월평균 클릭수·클릭률, 광고 경쟁 정도 | 네이버 검색광고 API |
| 블로그 누적 발행량, 카페 누적 발행량 | 네이버 검색 API |
| 최근 30일 블로그 발행량 (선택) | 네이버 검색 API (날짜순) |
| **포화지수 · 등급** | 발행량 ÷ 검색량 × 100 |
| 12개월 검색 추이 그래프 | 네이버 데이터랩 API |

**포화지수가 낮을수록 좋습니다.** 찾는 사람은 많은데 쓰인 글이 적다는 뜻이라서, 글을 쓰면 상위에 노출될 가능성이 높습니다.

---

## 1. API 키 발급 (무료)

### ① 검색광고 API → 검색량
1. https://searchad.naver.com 에 로그인합니다. 광고 계정이 없으면 만드세요. 광고비 충전은 필요 없습니다.
2. 상단 **도구 → API 사용 관리 → 네이버 검색광고 API 서비스 신청**
3. **액세스라이선스(API 키)**, **비밀키**, **CUSTOMER_ID** 세 가지를 복사합니다.

### ② 네이버 검색 API → 발행량 (NAVER API HUB)
> 2026년 7월 31일부터 네이버 개발자센터에서는 검색 API를 새로 발급받을 수 없습니다. 새 키는 **네이버 클라우드 플랫폼의 NAVER API HUB**에서 받습니다. 개발자센터에서 받아 둔 기존 키는 2027년 6월 30일까지 쓸 수 있습니다. 프로그램에서 「개발자센터 (기존 키)」를 고르면 됩니다.

1. https://www.ncloud.com 에서 회원가입·로그인 후 **콘솔**로 들어갑니다.
2. **Menu → All Services → Application Services → NAVER API HUB → Subscription → 이용 신청**을 누릅니다.
3. **Application → Application 등록**을 누릅니다.
   - API 선택 화면에서 **블로그**, **카페**를 고릅니다. 추이 그래프를 쓰려면 **검색어 트렌드**도 고릅니다.
   - 이름은 영문, 숫자, 하이픈만 쓸 수 있습니다 (예: `keyword-finder`).
4. 만든 Application의 **인증 정보**를 누르고 **Client ID**와 **Client Secret**을 복사합니다.

## 2. 설치

Python 3.10 이상이 필요합니다. https://www.python.org 에서 설치하세요.

```bash
pip install -r requirements.txt
```

## 3. 실행

**화면 버전 (추천)**
```bash
streamlit run app.py
```
Windows는 `실행.bat`을 더블클릭하면 되고, Mac은 터미널에서 `sh run.sh`를 실행합니다.
브라우저가 열리면 왼쪽에 키 5개를 넣고 **💾 키 저장**을 누릅니다. 저장은 처음 한 번만 하면 됩니다.

**명령줄 버전** (바로 엑셀로 저장)
```bash
python cli.py 캠핑의자 차박용품 --min 200 --max 150 --recent -o 결과.xlsx
```
`.env.example`을 `.env`로 복사한 뒤 키를 채워 두세요.

## 4. 등급 기준

| 등급 | 누적 발행량 기준 (기본) | 최근 30일 기준 |
|---|---|---|
| 🟢 매우좋음 | 50% 미만 | 10% 미만 |
| 🟢 좋음 | 200% 미만 | 30% 미만 |
| 🟡 보통 | 600% 미만 | 70% 미만 |
| 🟠 나쁨 | 2000% 미만 | 150% 미만 |
| 🔴 매우나쁨 | 그 이상 | 그 이상 |

기준값은 `analyzer.py`의 `grade()` 함수에서 바꿀 수 있습니다.

## 참고
- 검색량이 10 미만인 키워드는 네이버가 `< 10`으로 주기 때문에 5로 계산합니다.
- 검색광고 API는 키워드 안의 띄어쓰기를 지원하지 않아서 자동으로 붙여서 조회합니다.
- 블로그 검색은 최대 1,000건까지만 볼 수 있습니다. 최근 30일 글이 1,000건을 넘으면 발행 속도로 환산하고 `추정` 칸에 ✓를 표시합니다.
- `.env` 파일에는 API 키가 들어 있으니 다른 사람과 공유하지 마세요.
