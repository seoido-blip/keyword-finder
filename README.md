# 🔑 네이버 키워드분석 프로그램

블랙키위처럼 네이버 키워드의 **검색량, 월 발행량, 포화지수**를 보여주는 프로그램입니다. **검색은 많은데 글은 적은 '황금 키워드'**를 자동으로 찾아 줍니다.

- 내 PC에서 실행: `실행.bat`을 더블클릭합니다.
- 인터넷 사이트: https://naver-keyword-finder.streamlit.app (비밀번호 필요)

---

## 무엇을 할 수 있나요?

검색창에 `팔공산 맛집`, `대구 동구 맛집`처럼 입력하고 Enter를 누르면, 아래 4개 탭에 결과가 나옵니다.

| 탭 | 내용 |
|---|---|
| **기본 정보** | 월간 검색량(PC/모바일/합계), 월간 발행량(블로그/카페/전체), 콘텐츠 포화지수, 이번 달 예상 검색량, 키워드 등급 |
| **🏆 황금 키워드 추천** | 연관 키워드를 2단계로 넓게 모으고, '근처·주변·밥집·식당·추천' 같은 **비슷한 표현**도 만들어 검색량을 조회한 뒤, 추천점수 TOP 12를 카드로 보여 줍니다 |
| **📍 지역 키워드** | 지역을 자동으로 인식합니다(예: '팔공산' → 대구 동구). 같은 지역의 **동네·명소 키워드**와 **같은 시·도의 다른 구·군 비교**를 보여 줍니다 |
| **트렌드 분석** | 최근 12개월 월별 검색량, 최근 60일 일별 검색량 그래프 |

모든 숫자는 **한 달 기준**입니다. 표는 엑셀이나 CSV로 내려받을 수 있습니다.

### 지표 읽는 법
- **월 발행량**: 최근 30일 동안 새로 올라온 글 수입니다.
  - 글이 1,000건을 넘으면 최신 1,000건의 발행 속도로 한 달 치를 추정하고 `*` 표시를 붙입니다.
  - 카페 글은 작성일이 제공되지 않아서, 블로그 비율을 이용해 추정합니다.
- **포화지수** = 월 발행량 ÷ 월간 검색량 × 100입니다. **낮을수록 좋습니다.**
  - 10% 미만 매우 낮음 · 30% 미만 낮음 · 50% 미만 보통 · 70% 미만 높음 · 그 이상 매우 높음
- **추천점수(100점)** = 검색량 점수(50) + 경쟁 점수(50)입니다. 찾는 사람이 많고 글이 적을수록 높습니다.

> 블랙키위와 숫자가 똑같지는 않습니다. 네이버 공식 API는 최신 1,000개 글까지만 보여 주기 때문입니다. 대신 **키워드끼리 비교하고 순위를 매기는 용도**로는 충분합니다.

## 처음 설치하기

1. **Python 3.10 이상**을 설치합니다 (https://www.python.org). 설치할 때 "Add python.exe to PATH"를 체크하세요.
2. **API 키 5개**를 준비합니다. 모두 무료입니다.
   - **네이버 검색광고 API** (검색량): https://searchad.naver.com → 도구 → API 사용 관리 → 액세스라이선스 / 비밀키 / CUSTOMER_ID
   - **NAVER API HUB** (발행량, 트렌드): https://www.ncloud.com 콘솔 → NAVER API HUB → Subscription 이용 신청 → Application 등록(블로그, 카페, 검색어 트렌드 선택) → 인증 정보의 Client ID / Client Secret
     - 2026년 7월 31일부터 네이버 개발자센터에서는 검색 API를 새로 발급받을 수 없습니다.
     - 개발자센터에서 받아 둔 기존 키는 2027년 6월 30일까지 쓸 수 있습니다. 화면에서 「개발자센터 (기존 키)」를 고르면 됩니다.
3. `.env.example`을 복사해서 `.env`로 이름을 바꾸고 키를 채웁니다.
   - 또는 프로그램 화면 왼쪽 **🔐 API 키 설정**에서 입력하고 **💾 키 저장**을 누릅니다.
4. **`실행.bat`**을 더블클릭합니다. 필요한 패키지를 자동으로 설치하고 브라우저를 엽니다.
   - 검은 창은 프로그램 본체입니다. **닫지 마세요.**

## 명령줄로 바로 엑셀 만들기
```bash
python cli.py "팔공산 맛집"                # 기본 정보 + 황금 키워드 → 엑셀
python cli.py "대구 동구 맛집" --region    # 지역 키워드까지
python cli.py 캠핑의자 차박용품 --legacy   # 예전 방식(여러 시드의 연관 키워드 표)
```

## 잘 작동하는지 점검하기
`테스트실행.bat`을 더블클릭하거나 `python tests/test_all.py`를 실행합니다. 가짜 응답으로 핵심 계산을 점검하므로 API 한도를 쓰지 않습니다.

## 비용과 한도
- 검색광고 API와 Streamlit 사이트는 **무료**입니다. NAVER API HUB 검색 API는 **현재 한시적 무료**입니다(유료로 바뀌기 전에 사전 공지).
- NAVER API HUB는 하루 25,000회까지 쓸 수 있습니다.
  - 검색 한 번(황금 키워드와 지역 키워드 포함)에 300~800회를 씁니다.
  - 같은 키워드는 6시간 동안 저장된 결과를 보여 줘서 한도를 아낍니다.
- ⚠️ `.env`에는 API 키가 들어 있습니다. **다른 사람과 공유하거나 GitHub에 올리지 마세요.** `.gitignore`에 등록되어 있어서 GitHub에는 자동으로 올라가지 않습니다.
