## 다른 사람에게 알려 주기
**주소와 비밀번호**만 알려 주면 됩니다. 사용자는 설치나 키 없이 바로 씁니다.

## 비밀번호나 키 바꾸기
1. https://share.streamlit.io 에 들어갑니다.
2. 내 앱 옆 **⋮ → Settings → Secrets**를 누릅니다.
3. 내용을 고치고 **Save changes**를 누르면 1분 안에 반영됩니다.

Secrets 칸은 이런 모양입니다.
```
APP_PASSWORD = "사용자들에게 알려줄 비밀번호"

ENV = """
NAVER_AD_API_KEY=...
NAVER_AD_SECRET_KEY=...
NAVER_AD_CUSTOMER_ID=...
NAVER_CLIENT_ID=...
NAVER_CLIENT_SECRET=...
NAVER_API_PROVIDER=apihub
SUPABASE_URL=https://ziltjzkrmltmckeqkohy.supabase.co
SUPABASE_KEY=sb_publishable_...
"""
```
`ENV` 안에는 PC의 `.env` 파일 내용을 통째로 붙여넣으면 됩니다.

### 조회 결과 기록 (Supabase)
- `SUPABASE_URL`, `SUPABASE_KEY` 두 줄을 넣으면, 새로 조회한 결과가 Supabase의 `kw_results` 표에 쌓입니다.
  - 키는 Supabase **Project Settings → API Keys**의 공개용(publishable) 키입니다.
  - 두 줄이 없으면 기록만 안 되고, 분석은 그대로 됩니다.
- 기록 보기: Supabase 대시보드 → **Table Editor → kw_results**.
  - `kind` 칸으로 기본 정보 / 황금 키워드 / 지역 키워드를 구분합니다.
  - 6시간 안에 같은 키워드를 다시 보면 저장된 결과를 꺼내 쓰므로 새로 쌓이지 않습니다.

## 프로그램 고친 내용을 사이트에 반영하기
- **Claude에게 맡기기 (추천)**: "사이트에도 반영해줘"라고 하면 GitHub 저장소에 올려 줍니다. 1~2분 뒤 사이트에 자동으로 반영됩니다.
- **직접 하기**:
  1. GitHub 저장소 화면에서 **Add file → Upload files**를 누릅니다.
  2. 바뀐 `.py` 파일을 끌어다 놓습니다.
  3. **Commit changes**를 누릅니다.
  - ⚠️ `.env` 파일은 절대 올리지 마세요.

## 자주 생기는 일
| 증상 | 해결 |
|---|---|
| "Yes, get this app back up" 화면 | 며칠 안 써서 잠든 것입니다. 버튼을 누르면 1분 안에 켜집니다 |
| "관리자 설정이 아직 끝나지 않았습니다" | Secrets에 키가 없거나 형식이 틀렸습니다. 위 모양대로 다시 저장하세요 |
| 빨간 `removeChild` 오류 | 브라우저 자동 번역 때문입니다. 주소창의 번역 아이콘에서 '원본 표시'를 고르세요 (프로그램에서도 막아 두었습니다) |
| 발행량이 안 나오거나 오류가 남 | 하루 한도(25,000회)를 넘었을 수 있습니다. 다음 날 자동으로 풀립니다. 네이버 클라우드 콘솔의 **Usage Statistics**에서 확인하세요 |
| 사이트를 닫고 싶음 | share.streamlit.io에서 앱 **⋮ → Delete**를 누르거나, 비밀번호를 바꿉니다 |

## 비용
- Streamlit 사이트, 검색광고 API: **무료**
- NAVER API HUB 검색 API: **현재 한시적 무료**입니다. 유료로 바뀌기 전에 네이버가 미리 공지합니다.
  - 대비하려면 네이버 클라우드 콘솔 → NAVER API HUB → Application → **[한도 및 알림]**에서 사용 상한을 걸어 두세요.
