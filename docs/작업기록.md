# 작업기록 — 네이버 키워드분석 프로그램

Claude와 채팅으로 만든 과정을 순서대로 정리했습니다. 무엇을 **왜** 그렇게 바꿨는지 남겨 두면 다음에 고칠 때 도움이 됩니다.

## 1. 첫 버전 (2026-11-25)
- 목표: 블랙키위처럼 키워드의 검색량과 발행량을 보는 프로그램.
- 구성: 네이버 공식 API 두 가지를 사용했습니다.
  - 검색광고 API: 검색량, 연관 키워드.
  - 검색 API: 블로그·카페 문서 수.
- 포화지수는 처음에 '누적 문서 ÷ 검색량'으로 계산했습니다.
- 화면은 Streamlit으로 만들고, Windows에서는 `실행.bat`으로 실행합니다.
- 설치 중 겪은 문제와 해결:
  - `streamlit` 명령을 찾지 못함 → `python -m streamlit`으로 실행.
  - 첫 실행 때 이메일 입력 창이 멈춤 → credentials 파일을 자동으로 생성.

## 2. 네이버 정책 변경 대응 (2026-11-26)
- 2026-07-31부터 **네이버 개발자센터에서 검색 API를 새로 발급받을 수 없게** 되었습니다.
  - 그래서 키 발급 화면 목록에 '검색'이 없었습니다.
- **NAVER API HUB(네이버 클라우드)**를 지원하도록 바꿨습니다. 주소와 인증 헤더가 다릅니다.
- 기존 개발자센터 키도 고를 수 있게 했습니다 (2027-06-30까지 동작).

## 3. 블랙키위 스타일 대시보드
- 키워드 하나를 검색하면 카드형 화면으로 보여 주는 「기본 정보」 탭을 만들었습니다.
  - 월간 검색량, 월간 콘텐츠 발행량, 이번 달 예상 검색량, 콘텐츠 포화지수, 키워드 등급.
- 이번 달 예상 검색량: 데이터랩 일별 상대값을 검색광고 API의 최근 30일 검색량에 맞춰 환산했습니다.
- '캠핑의자'로 블랙키위와 비교한 결과:
  - 검색량은 일치했습니다 (46,900).
  - 이번 달 감소율도 일치했습니다 (-41.2%).

## 4. 🏆 황금 키워드 추천
- 연관 키워드를 2단계로 확장합니다. 상위 연관 키워드 5개를 다시 힌트로 넣어 한 번 더 모읍니다.
- **관련성 필터**를 넣었습니다. 기본값은 주제어(첫 단어) 포함입니다.
  - 띄어쓰기 없이 입력해도 연관 키워드를 보고 자동으로 나눕니다 ('팔공산맛집' → 팔공산 + 맛집).
- **추천점수(100점)** = 검색량 점수 + 경쟁 점수.

## 5. 📍 지역 키워드
- 전국 시·도와 시·군·구 표를 넣고, 검색어에서 지역과 업종을 알아냅니다.
- 같은 시·도의 다른 구·군과 비교합니다. 사람들이 검색하는 여러 형태 중 검색량이 가장 많은 것을 대표로 씁니다.
- **동네 판정 문제와 해결**:
  - 처음 결과(대구 동구 맛집)에 엉뚱한 곳이 섞였습니다: 해운대·명지(부산), 관평동(대전), 탕정(아산), '주변맛집'.
  - 그래서 블로그에서 **'대구 동구 + 동네'가 함께 언급되는 횟수**로 정말 그 구의 동네인지 확인하도록 했습니다.
  - 실측 수치를 보고 기준을 조였습니다. 마산, 진해, 왜관, 언양, 조치원, 동성로(중구)가 걸러집니다.
  - 화면의 「🔬 동네 판정 상세」에서 근거 수치를 볼 수 있습니다.
- **명소 이름만 검색해도 지역 추정**: 예를 들어 '팔공산 맛집' → 대구 동구로 인식합니다.

## 6. 모든 지표를 '한 달 기준'으로 (사용자 요청)
- 바꾼 이유: 카드의 '블로그 문서 56,173'이 누적 수치라 헷갈렸습니다.
- 바꾼 내용: 블랙키위처럼 **월 발행량(블로그/카페/전체)**과 **월 기준 포화지수**로 모두 통일했습니다.
- 검증: 팔공산갓바위로 계산했을 때 블랙키위와 거의 같았습니다.
  - 월 발행: 700/150/850 (블랙키위 700/160/860)
  - 포화지수: 1.78% (블랙키위 1.78%)
- 버그 수정:
  - 조회에 실패한 키워드가 0으로 잡혀 추천 2위에 올라감 → 다시 시도하고, 그래도 실패하면 추천에서 제외.
  - 카페 추정치가 터무니없이 커짐 → 상한을 걸었습니다.

## 7. 🔁 비슷한 표현 찾기 (사용자 요청)
- '팔공산맛집'을 검색하면 같은 뜻으로 바꿔 검색하는 표현을 자동으로 만들어 검색량을 조회합니다.
  - 예: 팔공산근처맛집, 팔공산주변맛집, 팔공산밥집, 팔공산식당, 팔공산맛집추천.
- 실제 결과 예시: 팔공산오리고기 2,350 · 팔공산한정식 1,470 · 팔공산밥집 1,160 · 팔공산근처맛집 450.
- 업종별 표현 목록이 있습니다: 맛집, 카페, 숙소, 펜션, 술집, 횟집, 가볼만한곳, 미용실, 병원.

## 8. 인터넷 배포 (2026-11-27)
- 배포 경로: GitHub `seoido-blip/keyword-finder` → Streamlit Community Cloud
  - 주소: https://naver-keyword-finder.streamlit.app
- 키 운영: 사용자 키를 공용으로 쓰고, 키는 Streamlit Secrets에만 둡니다. 사이트에는 비밀번호를 걸었습니다.
- 한도 절약: 같은 키워드는 6시간 동안 결과를 재사용합니다.
- 보안 수정: Secrets 없이 사이트가 먼저 열려 키 입력 칸이 노출됨 → 키가 없으면 안내만 보여 주고 멈추게 했습니다.
- 오류 수정: 엣지 자동 번역 때문에 `removeChild` 오류가 남 → 페이지에 '번역 안 함'을 표시했습니다.

## 남은 과제 / 아이디어
- 동네 후보가 네이버 연관 키워드에 의존합니다. 작은 동네(예: 신암동)는 빠질 수 있습니다.
  - 행정동 목록 데이터를 넣으면 개선됩니다.
- 판정 기준은 대구 데이터로 맞췄습니다. 다른 지역에서 오판이 보이면 「동네 판정 상세」 수치를 보고 조정하세요.
- 사용자가 많아지면 하루 한도(25,000회)가 부족할 수 있습니다.
